# 2023-2024년 대구광역시립달성도서관 대출 데이터 분석 및 기상 데이터 상관관계 분석
본 프로젝트는 2023년과 2024년 대구광역시립달성도서관의 도서 대출 데이터를 분석하고, 같은 기간의 대구 지역 기상 데이터(온도, 강수량, 일조시간, 적설량)와의 상관관계를 시각화하여 파악하는 것을 목표로 합니다.

## 분석 과정
데이터 준비
- 깃허브에 저장된 2023-2024년 대구광역시립달성도서관 대출 데이터(daegu_lib23_24.csv)를 Colab 환경으로 불러옵니다.
- 공공 데이터 포털의 기상청 데이터를 활용하여 2023년 9월부터 2024년 8월까지의 대구 지역 기상 정보를 API를 통해 불러옵니다.

## 데이터 전처리 및 병합
두 데이터셋의 날짜 형식을 통일하여 병합합니다.
기상 데이터의 결측치(공백)를 NaN으로 변환하고, 강수량(sumRn)과 적설량(ddMes)의 결측값은 0으로 처리합니다.

### 데이터 시각화 및 분석
성별에 따른 대출량 차이 분석
- 여성 대출 건수가 남성 대출 건수보다 약 2배 가까이 많은 것으로 나타났습니다.

### 온도에 따른 대출량 차이 분석
- 평균 기온이 1~10°C 구간에서 대출량이 가장 많은 것으로 나타났습니다.
- 무더운 30°C 이상 구간과 영하의 -10~0°C 구간에서는 대출량이 현저히 감소했습니다. 이는 날씨가 매우 덥거나 추울 때 도서관 방문객이 줄어들기 때문으로 추측됩니다.

### 강수량에 따른 대출량 차이 분석
- 비가 오지 않는 0mm일 때 대출량이 가장 많았습니다. 이는 맑은 날 도서관을 이용하는 사람이 많다는 것을 의미합니다.
- 강수량이 10mm 이상으로 많아질수록 대출량은 급격히 줄어들었습니다.

### 일조시간에 따른 대출량 차이 분석
- 일조시간이 9시간 이상인 맑은 날에 대출량이 가장 많았으며, 일조시간이 짧을수록 대출량이 감소하는 경향을 보였습니다.

### 적설량에 따른 대출량 차이 분석
- 적설량이 0cm인 날의 대출량이 압도적으로 많았습니다. 눈이 오는 날에는 도서관 방문이 줄어드는 경향을 확인할 수 있습니다.

## 결론
대구광역시립달성도서관의 대출 데이터 분석 결과, 성별로는 여성의 대출 비중이 높았으며, 기상 조건과 대출량 간에는 명확한 상관관계가 있음을 알 수 있었습니다. 특히, 온화하고 맑은 날에 도서관 대출이 활발하며, 폭염이나 추위, 비 또는 눈이 오는 날에는 대출량이 감소하는 경향을 보였습니다.
이러한 분석 결과는 도서관 운영 정책 수립이나 마케팅 전략에 활용될 수 있을 것입니다. 예를 들어, 날씨가 좋은 날에는 야외 행사나 프로그램, 날씨가 좋지 않은 날에는 실내 이벤트 등을 기획하여 이용률을 높이는 방안을 고려해볼 수 있습니다.
